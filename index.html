Download code and results

      
Runs the model many times at the parameters set on the left and saves everything in one zip: the model code and this page (unzip and open index.html to run it again), every run period by period, the mean and spread per period, each run's final values, the charts as images and the settings and seed. Nothing is uploaded; the zip is made in your browser. A number typed in the seed box is used as the base seed; otherwise a new one is drawn and recorded.
